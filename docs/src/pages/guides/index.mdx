`astro-git-dates` lets an entry in an Astro content collection take its date from git. Write
`date: git Last Modified` in the frontmatter, and at build time it becomes the date of the file's
last commit. It works like the
[Eleventy feature](https://www.11ty.dev/docs/dates/#setting-a-content-date-in-front-matter) of the
same name.

It is opt-in per entry. Entries with a normal date do not change, so you can move entries over one
at a time.

## Prerequisites

- Astro 5 or later.
- Collections that use a content loader, such as `glob()` from `astro/loaders`. The old
  `type: 'content'` collections do not give the loader a file path, so they cannot work.
- The site is built from a git checkout with full history.
